إطلاق حزمة مكتبة الوسائط المركزية للعالم

هذا الدليل يرافقك خطوة بخطوة لتحويل مجهودك البرمجي إلى حزمة معتمدة على Packagist وموقع Filament Plugins باسمك، وتتيح لأي مطور في العالم تثبيتها بسطر أوامر واحد مع دعم كامل لنسخ الأكواد والروابط بنقرة واحدة.

أمر تثبيت الحزمة العالمي (Composer Require):
composer require majid-shafik/filament-media-library
🛡️

كشف التكرار SHA-256

توليد بصمة بايتات فريدة لكل صورة لمنع تكرار التخزين وتوفير الجيجابايتات.

🌳

شجرة مجلدات هرمية

تنظيم التصنيفات بمستويات غير محدودة مع حماية كاملة من التكرار الحلقي.

فحص وتطهير أمني

إعادة ترميز عبر GD لمنع الـ Decompression Bombs وحذف أكواد EXIF الخبيثة.

1

المرحلة الأولى: الاختبار والربط المحلي (Symlink)

التأكد من أن الحزمة تعمل بنسبة 100% داخل مشروعك دون أي خطأ قبل رفعها للإنترنت.

بيئة التطوير المحلية

1.1 إضافة الحزمة في ملف composer.json الخاص بمشروعك (مثل sfd-new-site):

افتح ملف composer.json وأضف مستودع الـ Path المحلي لكي يقرأ Composer الملفات مباشرة من مجلد الحزمة:

composer.json 
"repositories": [
    {
        "type": "path",
        "url": "D:/taturial/Laravel/Filament/Filament Packages/packages/majid-shafik/filament-media-library",
        "options": {
            "symlink": true
        }
    }
]

1.2 تثبيت الحزمة عبر Terminal المشروع:

Terminal (داخل مجلد مشروعك) 
composer require majid-shafik/filament-media-library:@dev

1.3 تفعيل الـ Plugin في مزود لوحة التحكم (AdminPanelProvider.php):

app/Providers/Filament/AdminPanelProvider.php 
use MajidShafik\FilamentMediaLibrary\FilamentMediaLibraryPlugin;

public function panel(Panel $panel): Panel
{
    return $panel
        // ... الإعدادات الأخرى
        ->plugins([
            FilamentMediaLibraryPlugin::make(),
        ]);
}

1.4 تشغيل الميجريشنز ومسح الكاش:

Terminal 
php artisan migrate
php artisan optimize:clear
✓ علامة النجاح:
افتح المتصفح وادخل للوحة الإدارة؛ ستجد مجموعة "مكتبة الوسائط" ظهرت في القائمة الجانبية بشاشات استعراض الوسائط وشجرة التصنيفات بسلاسة تامة.
2

المرحلة الثانية: تجهيز Git والرفع إلى GitHub

رفع الحزمة إلى حسابك كمستودع عام مفتوح المصدر (Public Repository).

مستودع الكود

2.1 إنشاء مستودع جديد على GitHub:

1. افتح صفحة إنشاء المستودع الجديد في GitHub:

https://github.com/new

2. سمّ المستودع: filament-media-library
3. اختر نوعه: Public (عام).
4. لا تضع علامة صح على إضافة README أو LICENSE لأننا قمنا بتجهيزهما مسبقاً داخل الحزمة.

2.2 تهيئة Git ورفع الكود من جهازك:

افتح Terminal داخل مجلد الحزمة الفعلي وشغّل الأوامر التالية:

PowerShell / CMD 
cd "D:\taturial\Laravel\Filament\Filament Packages\packages\majid-shafik\filament-media-library"

git init
git add .
git commit -m "feat: initial release of filament-media-library v1.0.0"

git branch -M main
git remote add origin https://github.com/Majid-Shafik/filament-media-library.git
git push -u origin main

2.3 إصدار أول وسم رسمي (Release Tag):

الوسم (Tag) هو الذي يعتمده Composer لمعرفة رقم الإصدار المستقر:

Terminal 
git tag v1.0.0
git push origin v1.0.0
3

المرحلة الثالثة: النشر على Packagist

جعل الحزمة رسمية وقابلة للتثبيت لأي مطور في العالم عبر composer require.

مستودع الحزم العالمي

3.1 رابط الدخول إلى Packagist:

https://packagist.org
  1. سجل الدخول باستخدام حسابك في GitHub (Log in with GitHub).
  2. اضغط على زر Submit في القائمة العلوية.
  3. الصق رابط مستودع الـ GitHub التالي:
https://github.com/Majid-Shafik/filament-media-library

اضغط على Check ثم اضغط على Submit.

3.2 تفعيل التحديث التلقائي (GitHub Webhook):

في صفحة حزمتك على Packagist ستظهر رسالة تتيح لك تفعيل الـ Webhook بنقرة واحدة ليرسل التحديثات لـ Packagist تلقائياً عند أي Push على GitHub.

🎉 مبارك! حزمتك أصبحت عالمية:
الآن، يستطيع أي مبرمج حول العالم فتح أي مشروع لارافيل وتشغيل هذا الأمر:
composer require majid-shafik/filament-media-library
4

المرحلة الرابعة: التقديم لدليل Filament الرسمي

إدراج حزمتك رسمياً في قائمة filamentphp.com/plugins للوصول لآلاف المطورين.

دليل Filament الرسمي

4.1 رابط تقديم البلجن:

https://filamentphp.com/community/submit-plugin
  1. سجل دخولك بحساب GitHub.
  2. املأ بيانات الحزمة (يمكنك نسخ القيم المباشرة بنقرة واحدة):
Name: Filament Media Library
Package Name: majid-shafik/filament-media-library
Repository URL: https://github.com/Majid-Shafik/filament-media-library

4.2 نصائح مهمة للقبول السريع:

  • الصور (Screenshots): ارفع صورتين إلى 3 صور أنيقة لواجهة استعراض الوسائط، شجرة التصنيفات، وبطاقة التنبيه بالتطابق.
  • التوثيق: ملف الـ README الجاهز داخل الحزمة يفي بجميع المتطلبات الرسمية.
⚡

أوامر سريعة ونصائح صيانة الحزمة

أوامر ستحتاجها لاحقاً عند إصدار تحديثات جديدة.

كيف تصدر تحديثاً جديداً للحزمة مستقبلاً؟ (مثلاً v1.0.1):

Terminal 
# 1. بعد تعديل الكود:
git add .
git commit -m "fix: improve image upload validation"
git push origin main

# 2. إنشاء تاج إصدار جديد:
git tag v1.0.1
git push origin v1.0.1

أمر حساب بصمات SHA-256 للصور القديمة في أي مشروع يستخدم الحزمة:

php artisan media:backfill-hashes --all
تم النسخ بنجاح إلى الحافظة!
